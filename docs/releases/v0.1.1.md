# JSON Analyzer v0.1.1 — The Bundle Gate Opens

## The Quest
The first forge-fire proved the app could stand, but the release gate stayed shut: CI compiled the desktop shell without creating package artifacts. This patch release turns the release path into a real packaging ritual while keeping the local-first analyzer unchanged.

## What Awoke
- A tag-triggered release workflow that creates the GitHub release from these lore notes.
- Linux, macOS, and Windows packaging jobs that build unsigned Tauri bundles.
- Automatic release-asset upload for the generated installers and desktop bundles.
- The CI dependency fix that installs Tauri Linux system libraries before Tauri checks run.
- Aligned `0.1.1` version metadata across Rust, Tauri, and package manifests.

## Runes of Assurance
- `pnpm check` passed locally before the release cut.
- The fixed `main` CI run passed on GitHub Actions.
- The previous `gdk-3.0` Actions failure is covered by the new dependency setup in the `Check` job.

## Known Boundaries
- Release bundles are unsigned; Windows and macOS may show the usual trust prompts.
- Release assets are private while the repository remains private, so downloads require repository access.
- Auto-update metadata, notarization, and public distribution policy are still deferred.
