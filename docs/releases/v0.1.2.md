# JSON Analyzer v0.1.2 — The Mirror Tabs Align

## The Quest
The analyzer had learned its craft, but the visible workflow still carried too much of its workshop scaffolding. This release brings the Values and Duplicates tabs closer to the target app’s shape while modernizing the frontend architecture underneath, so the interface feels calmer without weakening the local-first Rust core.

## What Awoke
- Target-style Values Explorer behavior with compact field selection, field/value filtering, frequency/alphabetical sorting, duplicate-first results, all-values pagination, expandable groups, and focused copy actions.
- A Duplicates tab that follows the target exact-duplicates flow: count-aware tab chrome, collapsed duplicate groups, icon actions, warning/success states, and target metric language.
- A typed command adapter split that keeps Tauri IPC behind domain wrappers while preserving existing command names and backend DTOs.
- React Query for desktop command state and Zustand for safe UI/session state, with persistence limited to lightweight preferences.
- Split browser mocks, feature modules, shared UI primitives, and CSS entry points so future parity work has cleaner boundaries.
- Values Explorer backend support for independent duplicate/all-results paging and bounded preview-item collection per group.
- Updated app icons and release packaging metadata for the new cut.

## Runes of Assurance
- `pnpm run check` passed locally before the release cut.
- Final observed suite: Rust 105 tests, Tauri 4 tests, frontend 11 files / 89 tests.
- Architecture guard tests now check raw Tauri invoke boundaries, frontend command names, Tauri permissions, and registered command handlers.

## Known Boundaries
- Release bundles are still unsigned; Windows and macOS may show platform trust prompts.
- Curl jobs remain in-memory only; durable job history is still deferred.
- PDF export UI, auto-update metadata, notarization, and public distribution policy are not configured yet.
