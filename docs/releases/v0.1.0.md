# JSON Analyzer v0.1.0 — The Local JSON Forge

## The Quest
JSON Analyzer begins as a local-first desktop tool for people who need to inspect JSON without sending payloads to a remote service. This first release brings the Rust analysis core, Tauri desktop shell, and React interface together into one guarded workflow.

## What Awoke
- Local JSON validation, formatting, sample loading, and duplicate-key-preserving analysis.
- Statistics, Values, and Duplicates views for understanding structure, field patterns, grouped values, and exact duplicate records.
- Values Explorer with field discovery, grouped-value search/sort/pagination, duplicate-value insights, and parent/source detail previews.
- Guarded curl parsing, preview, single execution, batch jobs, cancellation, redaction, timeout/response limits, and private-network guardrails.
- Narrow Tauri command IPC with no localhost backend server and no broad frontend HTTP/filesystem/shell permissions.
- Restructured Rust, Tauri, and frontend tests so the suite is easier to navigate and preserve.

## Runes of Assurance
- `pnpm check` passed.
- `pnpm tauri:build:no-bundle` passed.
- Final observed suite: Rust 103 tests, Tauri 4 tests, frontend 8 files / 79 tests.

## Known Boundaries
- Curl jobs are in-memory only; there is no durable job history.
- PDF export UI and general save/download flows are deferred.
- Release signing, notarization, and installer distribution policy are not configured yet.
