# JSON Analyzer v0.1.3 — The Signed Path Opens

## The Quest
The app could already be forged into local bundles, but the road from CI to a trusted desktop install was still unfinished. This release turns the packaging path into a signed distribution flow for Linux and macOS, with clear install instructions for people who just want to run JSON Analyzer.

## What Awoke
- Linux CI now builds reusable `.deb`, `.rpm`, and `.AppImage` release artifacts from the passing frontend build.
- Debian packages can be signed in CI, then verified again before release publishing.
- A signed APT repository is generated for each release and deployed to GitHub Pages.
- A release-published repository setup script verifies a GPG-signed SHA256 sidecar before installing the JSON Analyzer APT source and archive keyring.
- Linux desktop and AppStream metadata now support discovery in GNOME Software and Ubuntu Software after APT metadata refresh.
- macOS release jobs now build Apple Silicon and Intel DMGs with signing and notarization support.
- The README now gives concise end-user install paths for macOS, APT-based Linux installs, software-center discovery, and direct package fallback downloads.

## Runes of Assurance
- `pnpm check` passed locally before the release cut.
- `desktop-file-validate src-tauri/linux/com.jsonanalyzer.desktop.desktop` passed with only a category hint.
- `appstreamcli validate --no-net src-tauri/appstream/com.jsonanalyzer.desktop.metainfo.xml` passed with only the expected content-rating info.
- Workflow YAML parsing, packaging script compilation, shell syntax checks, and `git diff --check` passed.

## Known Boundaries
- The first tagged GitHub Actions run still needs to prove the full hosted release path against GitHub Pages and Apple notarization.
- The APT repository currently publishes Linux `amd64` packages only.
- Curl jobs remain in-memory only; durable job history is still deferred.
- PDF export UI, auto-update metadata, and Windows signing remain outside this release.
